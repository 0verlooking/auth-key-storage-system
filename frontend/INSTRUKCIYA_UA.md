# Інструкція по запуску Frontend - Auth Key Storage System

## Швидкий старт

### 1. Встановлення залежностей

```bash
cd /home/user/auth-key-storage-system/frontend
npm install
```

Це встановить всі необхідні пакети (React, Material-UI, та інші).

### 2. Налаштування оточення

```bash
# Файл .env вже створений, але можна переглянути налаштування
cat .env

# Або відредагувати за потреби
nano .env
```

Основні налаштування:
- `VITE_API_URL` - адреса backend API (за замовчуванням http://localhost:8080)
- `VITE_PBKDF2_ITERATIONS` - кількість ітерацій для шифрування (100000)
- `VITE_SESSION_TIMEOUT` - час сесії (1 година)

### 3. Запуск development сервера

```bash
npm run dev
```

Додаток буде доступний за адресою: **http://localhost:3000**

### 4. Побудова для production

```bash
npm run build
```

Результат буде в директорії `dist/`

## Безпека

### Клієнтське шифрування

Всі чутливі дані шифруються на клієнті:

1. **Master Password** - ніколи не відправляється на сервер
2. **PBKDF2** - 100,000 ітерацій для деривації ключа
3. **AES-256-GCM** - шифрування з аутентифікацією
4. **Випадкові Salt і IV** - для кожного шифрування

### Потік шифрування

```
Користувач вводить Master Password
    ↓
PBKDF2 (100,000 ітерацій)
    ↓
Отриманий ключ (256-bit)
    ↓
AES-256-GCM шифрування
    ↓
Зашифровані дані (з salt + IV)
    ↓
Зберігання на сервері
```

## Перше використання

### 1. Реєстрація
1. Відкрийте http://localhost:3000
2. Натисніть "Sign up"
3. Заповніть форму:
   - Ім'я
   - Email
   - Пароль (мін. 8 символів)
   - Master Password (мін. 12 символів) - **ВАЖЛИВО!**
4. Натисніть "Create Account"

**⚠️ УВАГА**: Master Password не можна відновити! Запам'ятайте його!

### 2. Вхід
1. Введіть Email
2. Введіть Password
3. Введіть Master Password
4. Натисніть "Sign In"

### 3. Створення першого ключа
1. На Dashboard натисніть "Add Key"
2. Заповніть форму:
   - Назва (наприклад, "GitHub")
   - Тип (Password, API Key, тощо)
   - Username (опціонально)
   - Пароль (введіть або згенеруйте)
   - URL (опціонально)
   - Нотатки (опціонально)
3. Натисніть "Create"

### 4. Генерація пароля
1. В діалозі створення ключа натисніть іконку кубика (🎲)
2. Налаштуйте параметри:
   - Довжина (8-128 символів)
   - Великі літери
   - Малі літери
   - Цифри
   - Символи
3. Натисніть "Use Password"

## Можливі проблеми

### Порт зайнятий
```bash
# Змініть порт
PORT=3001 npm run dev
```

### Помилка підключення до API
- Переконайтесь що backend запущений
- Перевірте `VITE_API_URL` в `.env`
- Перевірте CORS налаштування backend

### Помилки шифрування
- Перевірте правильність Master Password
- Перегляньте консоль браузера
- Переконайтесь що браузер підтримує Web Crypto API
