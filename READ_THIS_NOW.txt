ПРОБЛЕМА БУЛА НЕ В ОДНОМУ МІСЦІ, А В 5 РІЗНИХ МІСЦЯХ!


🔴 ПРОБЛЕМА #1: SearchBar
--------------------
SearchBar.jsx мав useEffect який спрацьовував при КОЖНІЙ зміні onSearch функції

❌ Було:
useEffect(() => {
  onSearch(debouncedValue);
}, [debouncedValue, onSearch]); // ← onSearch змінювалась постійно!

✅ Виправлено:
useEffect(() => {
  onSearch(debouncedValue);
}, [debouncedValue]); // Тільки debouncedValue


🔴 ПРОБЛЕМА #2: DashboardPage handleSearch
----------------------------------------
handleSearch НЕ була обгорнута в useCallback → створювалась нова при кожному рендері

❌ Було:
const handleSearch = async (query) => {...}

✅ Виправлено:
const handleSearch = useCallback(async (query) => {...}, [folderId])


🔴 ПРОБЛЕМА #3: DashboardPage onRefresh
--------------------------------------
onRefresh створювалась inline як нова функція КОЖНОГО разу

❌ Було:
<AuthKeyList onRefresh={async () => {...}} />

✅ Виправлено:
const handleRefresh = useCallback(async () => {...}, [folderId])
<AuthKeyList onRefresh={handleRefresh} />


🔴 ПРОБЛЕМА #4: NotificationContext value
----------------------------------------
value об'єкт створювався новий при кожному рендері

❌ Було:
const value = { notifications, addNotification, ... }

✅ Виправлено:
const value = useMemo(() => ({...}), [deps])


🔴 ПРОБЛЕМА #5: handleKeySaved
-----------------------------
Також не була в useCallback

✅ Виправлено:
const handleKeySaved = useCallback(async () => {...}, [folderId])

                    ЯК ЦЕ СТВОРЮВАЛО INFINITE LOOP:

═══════════════════════════════════════════════════════════════════════════════

1. DashboardPage рендериться → створює НОВУ handleSearch функцію
2. SearchBar отримує нову onSearch prop → useEffect спрацьовує
3. useEffect викликає onSearch(debouncedValue) → handleSearch виконується
4. handleSearch викликає fetchAuthKeys() або searchAuthKeys()
5. AuthKeyContext змінює authKeys → value об'єкт стає НОВИМ
6. Всі споживачі AuthKeyContext rerenderяться (включно з DashboardPage)
7. NotificationContext теж створює новий value → ще більше rerenders
8. DashboardPage rerenders → GOTO STEP 1 → INFINITE LOOP!!!
